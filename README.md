# Card Scanner FREE (Android)

Reads visiting cards on the phone with Google ML Kit. No API key, no cost, works offline. Front and back are combined into one row. Optional Google Sheet sync and CSV export.

Build: upload all files to a GitHub repository, open Actions, wait for the green tick, download "app-debug-apk" from Artifacts.

Note: reading is rule-based, so check each row. One photo (or one front+back pair) is treated as ONE card.
